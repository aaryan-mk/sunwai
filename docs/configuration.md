# Configuration reference

Generated by `scripts/gen_config_docs.py`; do not edit by hand.

Every setting defaults to *unset*, which means the engine's built-in default applies. A canonical name
(`SUNWAI_<GROUP>__<FIELD>`) overrides the legacy flat name. Booleans accept `true/false/1/0/yes/no/on/off`.
